\# NQU 校務系統



\## 一、專案介紹



本專案為 NQU 校務系統，主要提供學生校務相關功能的網頁介面。



透過 HTML、CSS 與 JavaScript 製作網站，讓使用者可以透過瀏覽器操作系統功能。



\## 二、使用技術



\* HTML

\* CSS

\* JavaScript



\## 三、專案內容



本專案主要包含以下檔案：



\* `index.html`：系統首頁及登入相關頁面

\* `dashboard.html`：登入後的系統主頁面

\* `css/style.css`：網站版面與樣式設定

\* `js/app.js`：系統主要功能程式

\* `js/auth.js`：登入與驗證相關功能

\* `js/data.js`：系統資料相關內容



\## 四、系統功能



本系統提供以下功能：



1\. 使用者登入

2\. 校務系統首頁

3\. 系統功能選單

4\. 資料顯示與管理

5\. 使用 JavaScript 進行網頁互動

\## 六、執行方式



1\. 下載或複製本專案。

2\. 使用瀏覽器開啟 `index.html`。

3\. 依照網頁上的操作進行使用。

4\. 登入後可進入 `dashboard.html` 查看系統功能。



\## 七、開發目的



透過本次作業學習 HTML、CSS 與 JavaScript 的整合應用，並練習網頁介面設計、JavaScript 程式撰寫以及 Git / GitHub 版本控制的使用。
