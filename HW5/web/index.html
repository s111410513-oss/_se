Docker 學習重點紀錄

Image & Container
使用 Dockerfile 建置 Image，並以其建立隔離的 Container
docker-compose
統一定義多個服務、網路、資料卷，一鍵啟動整個系統
Multi-stage / 環境建置
針對 Node.js、Rust、Python 分別撰寫對應的 Dockerfile
Network & DNS
透過 Service Name（如 postgres、node-api）在內部網路互相溝通
Volume
使用 pg_data 保存 PostgreSQL 資料，實現持久化
Reverse Proxy
以 Nginx 統一路由，達成微服務入口集中管理
